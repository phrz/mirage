## 3. What the measurements decided

- **Lossless tiles use WebP** (libwebp), ~550 B per 64 px text tile, 2x better than Apple's
  Compression framework; predictors make UI content worse; near-lossless only pays on photos.
- **Video is for motion only.** Scroll/drag cost ~3 KB per frame at 36–38 dB at 800 kbps, but a
  single changed text tile through video is 1 KB at 20 dB (mush) versus 0.55 KB lossless. That is
  the measured case for the hybrid codec in M2.
- **The keyframe is the stall** (72–161 KB), now mitigated with a QP floor; later avoided by LTR.
- **SCK dirtyRects are complete and ~1.6x coarse on motion**; GPU diff only if the sparse-scene
  number (not yet measured, needed a quiet screen) says so.
- **Native menu bar is feasible**: full AX menu trees walk in 66–520 ms without opening menus.
- **Typed-text prediction is AppKit-only**: caret bounds + fonts work for Mail/Finder/Sketch,
  not Chromium, not Electron. Realistic coverage is native apps and terminals, not browsers.
- **Status items are not windows** on macOS 27; the menu bar is one Window Server window, so the
  remote extras strip is a crop of it.
- Link right now: ~4.5 Mbps each way by scp, RTT 158–245 ms bimodal, 0 loss.
