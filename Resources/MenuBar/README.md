# Menu-bar icon

Template images (monochrome, alpha only) for the menu-bar app, 18×18 pt at 1x and 2x (the mac idiom has no 3x), `template-rendering-intent: template`
so AppKit tints them for light, dark and highlighted menu bars.

- `MirageMenuBar.imageset` — pointer over two parallel heat-shimmer waves (same phase, constant gap, round caps).
- `MirageMenuBarStatus.imageset` — same glyph shifted left and shortened so the top-right 6×6 pt is empty for the updater's yellow dot.
- `vector/*.pdf` — single-scale vector sources of both glyphs.

Generated by the `menubar` plugin command in `../AppIcon/Source/mirage-icon.sketchplugin` (page "Menu Bar" in the Sketch document);
`preview-sheet.png` shows both on light, dark and active bars at 1x and 2x.
